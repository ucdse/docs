@startuml
title DublinBikes - User Login & Session Creation

actor User
participant "loginPage : LoginPage" as UI
participant "userRoutes : UserRoutes" as API
participant "userService : UserService" as US
participant "userRecord : User" as UserObj

User -> UI: submitCredentials(email, password)
activate UI

UI -> API: login(email, password)
activate API

API -> US: login_user(email, password)
activate US

US -> UserObj: query_by_email(email)
activate UserObj
UserObj --> US: User instance
deactivate UserObj

US -> US: verify_password(password)
US -> US: create_access_token(user_id, version)
US -> US: create_refresh_token(user_id, version)

US --> API: auth_tokens
deactivate US

API --> UI: auth_tokens
deactivate API

UI -> UI: storeTokensLocal()
UI -> UI: navigateToDashboard()

UI --> User: Display Dashboard
deactivate UI

@enduml
