@startuml
title DublinBikes - User Login & Session Creation

actor User
participant "loginPage : Login" as UI
participant "userRoutes : UserRoutes" as API
participant "userService : UserService" as US
participant "werkzeug.security" as WZ
participant "database : SQLAlchemy ORM" as DB

User -> UI: click SignIn (trigger handleSubmit)
activate UI

UI -> API: userLoginAPI({identifier, password})
activate API

API -> US: login_user(email, password)
activate US

US -> DB: query User by identifier
activate DB
DB --> US: User instance
deactivate DB

US -> WZ: check_password_hash(password_hash, password)
activate WZ
WZ --> US: is_valid (Boolean)
deactivate WZ
US -> US: create_access_token(user_id, version)
US -> US: create_refresh_token(user_id, version)

US --> API: auth_tokens
deactivate US

API --> UI: auth_tokens
deactivate API

UI -> UI: setAuthTokens(vo)
UI -> UI: navigate('/profile')

UI --> User: Display Dashboard
deactivate UI

' =====================================
' TOKEN REFRESH FLOW (On Expiration)
' =====================================
... time passes ...

User -> UI: Trigger Protected Action
activate UI

UI -> API: protectedapi_call() [Header: Authorization Bearer AccessToken]
activate API
API --> UI: 401 Unauthorized (Token Expired)
deactivate API

UI -> API: POST /api/users/refresh [Body: {refresh_token}]
activate API
API -> US: refresh_tokens(refresh_token)
activate US
US -> US: verify_refresh_token(refresh_token)
US -> US: create_access_token(user_id, version)
US --> API: new_auth_tokens
deactivate US

API --> UI: new_auth_tokens
deactivate API

UI -> UI: updateTokensLocal()
UI -> API: retry_protected_api_call() [Header: Authorization Bearer NewAccessToken]
activate API
API --> UI: 200 OK Response
deactivate API

UI --> User: Action Succeeded
deactivate UI

@enduml
